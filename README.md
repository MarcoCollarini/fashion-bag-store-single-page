# Fashion Bag Store Trieste - demo offline

Apri `index.html` con un browser moderno. Non sono richiesti server, CDN o connessione Internet per visualizzare il sito.

## Struttura
- `index.html` pagina principale
- `css/style.css` stile responsive
- `js/main.js` menu, animazioni, lightbox e testimonianze
- `assets/img` immagini locali generate per la demo
- `assets/logo` logo SVG locale

Nota: il pulsante Indicazioni apre Google Maps e richiede Internet. Il sito e la mappa grafica interna funzionano offline. Gli orari sono indicati come demo e vanno verificati con il titolare prima della pubblicazione.
